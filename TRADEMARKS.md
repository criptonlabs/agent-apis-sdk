- Saying, truthfully, that your project uses, is compatible with or is built on the Criptonlabs Agent APIs or the official packages.

## Not allowed

- Publishing a fork, a modified copy or any other package under a name, scope, description or logo that suggests it is official, or that it comes from or is endorsed by Criptonlabs.
- Pointing a fork at another service while presenting it as the Criptonlabs Agent APIs, or presenting another service as the Criptonlabs Agent APIs.

## Forks

A fork must use its own name, must state clearly that it is not affiliated with or endorsed by Criptonlabs, and, as the Apache License requires, must carry prominent notices in every file it modifies. The original authors are not responsible for modified copies.
